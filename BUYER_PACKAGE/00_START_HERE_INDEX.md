## How to hand one out (the 5-minute flow)

1. Copy the whole `BUYER_PACKAGE/` folder to a new folder named for the restaurant.
2. Open `CUSTOMIZE/RESTAURANT_PROFILE.md`, fill in the fields for that business.
3. Find-and-replace the `{{MERGE_FIELDS}}` across the copied files (see `CUSTOMIZE/HOW_TO_CUSTOMIZE.md`).
4. Export the CORE files to PDF (or print) — that's the leave-behind.
5. Bring the live demo on your phone (`06_SEE_IT_LIVE.md`) — the demo closes, the folder reminds.

> **Golden rule:** the CORE copy is the same for everyone so nobody gets a different story.
> Only the `{{FIELDS}}` change. If it isn't a `{{FIELD}}`, don't rewrite it.
