# Colattanini Sticker Specs

## Status

Planning/spec only. No final artwork has been approved in this document.

## Sticker Set

Create three individual stickers:

1. **Churro Chispa**  
   Tied menu item: Churro Latte.

2. **Coco Beach Blitzer**  
   Tied menu item: Coco Beach.

3. **Cali Croissant Captain**  
   Tied menu item: California Sandwich.

## Approximate Size

- Individual die-cut stickers: **2.25 in x 2.25 in** target footprint.
- Keep each character readable at **2 in** minimum.
- Avoid thin details that disappear on a phone photo or small print.

## Print Format

- Final print files: CMYK-ready PDF or PNG, 300 DPI.
- Art working files: layered source file if available, plus transparent PNG export.
- Bleed: 0.125 in.
- Safe margin: 0.125 in inside the cutline.
- Cutline: separate vector path or clear dieline layer.
- Background: transparent or simple cream outline; no full photographic backgrounds.

## Finish Recommendation

- Matte vinyl or soft-touch matte.
- Water-resistant finish.
- Rounded die-cut edge around character silhouette.
- Avoid glossy glare because customers may photograph the sheet/stickers under cafe lighting.

## Art Requirements

- Use the approved Colattao palette: warm espresso, cream/parchment, gold/caramel, plus character accents.
- Do not print menu prices.
- Do not include QR codes on the stickers.
- Do not generate readable menu text inside image models.
- Do not use warped/generated Colattao logos.
- If a logo is used, use an approved transparent Colattao logo asset only.
- No FIFA, World Cup, official tournament, federation, or official ball marks.
- No real human faces unless written likeness rights are approved.
- Character art should be original, cute, and clearly non-human/product-inspired.
- Each sticker should include the character name and small tied item label only if text remains readable.

## Individual Art Direction

### Churro Chispa

- Menu item: Churro Latte.
- Shape language: latte cup, cinnamon swirl, tiny striker stance.
- Palette: caramel, cream, cinnamon brown, warm gold.
- Pose: mid-kick with a cinnamon trail.
- Read: playful first collectible.

### Coco Beach Blitzer

- Menu item: Coco Beach.
- Shape language: cold foam crest, coconut/tropical motion, sunny side-volley.
- Palette: cream, coconut white, soft blue, beach gold.
- Pose: flashy volley or celebratory slide.
- Read: seasonal, bright, energetic.

### Cali Croissant Captain

- Menu item: California Sandwich.
- Shape language: croissant captain, avocado sash, savory sandwich cue.
- Palette: croissant gold, avocado green, cream, espresso outline.
- Pose: captain shielding the ball or pointing toward goal.
- Read: premium final collectible.

## Production Notes

- Print a small first batch before committing to volume.
- Recommended first batch: 50 of each character.
- Keep extra uncut proof sheet for staff reference.
- Final art must pass the asset QA checklist before print.
