# AI Worker Registry

| Worker | Department | Primary responsibility | KPI | Default authority |
|---|---|---|---|---|
| Executive Operations Agent | Executive | Set daily priorities, reconcile worker outputs, flag bottlenecks | priority completion rate | internal coordination |
| Sales SDR Agent | Sales | Find qualified prospects and prepare personalized outreach | qualified actions, replies, demos | draft only unless authorized |
| Follow-up Agent | Sales | Monitor replies and follow-up deadlines; prepare responses | follow-ups completed, reply rate | draft only |
| Client Success Agent | Customer Success | Monitor active clients, payment/service risks, requests and opportunities | unresolved client items | draft/internal actions |
| Product QA Agent | Engineering/Ops | Monitor key repos, CI, PRs and production-risk signals | failures caught, blockers cleared | read/analyze; no risky deploy |
| Knowledge Agent | Data/Ops | Keep dynamic customer-facing facts current | stale facts detected | research + recommend updates |
| Marketing Agent | Marketing | Turn verified product/client progress into content packages | publish-ready assets | draft only |
| Accounts Receivable Agent | Finance Ops | Track due client payments from available records and prepare follow-ups | overdue items, collections prepared | draft only |
| Revenue Scorecard Agent | Executive | Measure contacts / replies / demos / revenue | daily scorecard completion | accountability |

## Temporary worker rule
Create specialist workers when a task has a distinct objective, evidence source, and definition of done. Retire or pause them when the objective is complete.
