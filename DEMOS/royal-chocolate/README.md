# Chocolate Counter — unsent local concept
Routes: /royal-chocolate and /royal-chocolate/play.
Implementation: APP/web/src/app/royal-chocolate. Original SVG art: APP/web/public/assets/royal-chocolate.
Imports the owned collector-standard engine/rules unchanged. Royal-only configuration supplies pickups, targets, three spaced counter layouts and growth stages. Counts116/170/232, targets1300/2200/3200, one/two/three rivals; standard45s limits, increasing speed/reaction and gather/contest/hunt behaviors. Canvas2D presentation deliberately follows the existing collector reference without extra dependencies, external runtime assets or a second artifact build.
All game art is illustrative. Items inspired by evidenced fondue dippers/apple offerings; chocolate squares are generic illustrative pickups, not a promised retail SKU. Proposed title lettering is original display artwork, not a recreated business logo. Optional SVG loads use product-shaped primitives when unavailable. Assets never change capture geometry.
Controls: one-finger relative drag, pointer-held direction buttons, arrow keys/WASD and keyboard-held direction buttons. Pointer cancel/loss, key release, blur and hidden tab clear intent. Hidden tab/blur pause. Win requires target and strict score lead; loss explains capture, missed target or rival lead. Counter clear/time/capture lock an immutable result and halt simulation. Replay re-creates the race. All counters selectable for review.
Local-only authorization. No rewards, payment, ordering, live participation or customer approval. See OPERATIONS/ROYAL_CHOCOLATE/2026-10-13 for source and verification records.
