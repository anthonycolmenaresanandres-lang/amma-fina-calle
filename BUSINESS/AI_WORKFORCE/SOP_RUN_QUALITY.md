# SOP — Worker Run Quality

Each weekly Workforce Review evaluates every recurring worker on:

1. Outcome value (0–3)
   - 0 noise/no usable output
   - 1 useful information
   - 2 caused a concrete next action
   - 3 produced measurable business progress

2. Evidence quality (0–3)
   - unsupported → fully source-grounded

3. Handoff quality (0–2)
   - unclear ownership → exact owner/next step/trigger

4. Duplication/noise penalty (0 to -2)

5. False-completion penalty (0 to -3)

## Management rules
- Two consecutive low-value weeks: recommend prompt/schedule change.
- Three consecutive low-value weeks: recommend pause/retirement.
- Repeated overlap: merge responsibilities instead of adding another worker.
- Repeated manual founder intervention: candidate for a new SOP.
- Repeated success with the same sequence: candidate for automation.

Never optimize for number of runs. Optimize for verified outcomes.
