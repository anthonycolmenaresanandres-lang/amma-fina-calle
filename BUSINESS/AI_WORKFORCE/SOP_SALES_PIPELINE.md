# SOP — Sales Pipeline

## Prospect Research
Goal: create verified opportunities, not giant lead lists.
1. Start from ICP: restaurants/cafes for digital experience; local service businesses for AI Front Desk; sports facilities/operators for GameDay Content.
2. Verify business exists and fit is current.
3. Identify the most relevant decision-maker/role when possible.
4. Record source and why the offer fits.
5. Add only qualified prospects to STATE.json as RESEARCHED.
6. Do not draft generic spam.

## Revenue Agent
1. Read STATE.json before new research.
2. Work warm and due opportunities first.
3. Select at most 5 highest-value actions.
4. New outreach must be personalized to a verified problem/signal.
5. Create DRAFT_READY handoff; do not send.

## Follow-up Agent
1. Use Gmail evidence as source of truth.
2. Update CONTACTED/REPLIED only when message evidence exists.
3. Prepare follow-up only when due.
4. Avoid 'just checking in'; add a useful reason to respond.
5. Route buying signals to Demo/Proposal.

## Demo / Proposal
1. Use only verified product capabilities.
2. Define the customer's problem before features.
3. Demo working proof.
4. State limitations explicitly.
5. Propose the smallest useful pilot.
6. Do not invent enterprise pricing or integrations.

## Definition of done
Sales work is not complete at draft creation. Close the loop only with evidence: sent, replied, meeting held, proposal delivered, won/lost.
