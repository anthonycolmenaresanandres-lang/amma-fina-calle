# SOP — Process Engineering

Purpose: make AMMA / Fina Calle easier to operate every week.

A task qualifies for an SOP when it:
- happened at least twice;
- has repeatable inputs and outputs;
- causes errors, delay, or founder attention;
- can be checked with objective evidence.

For each SOP:
1. Define the trigger.
2. Define the owner.
3. Define required inputs.
4. Write the shortest reliable procedure.
5. Define acceptance evidence.
6. Define STOP / escalation conditions.
7. Identify automation opportunities.
8. Trial before making it standard.

Never automate a broken or unverified process merely because it repeats.

The Process Engineer may draft or improve files under BUSINESS/AI_WORKFORCE on branch ops/ai-workforce-state. Product code, production release, external sends, spending, access, and secrets remain separately gated.
