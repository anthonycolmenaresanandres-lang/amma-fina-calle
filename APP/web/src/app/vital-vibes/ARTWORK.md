# Vital Vibes photorealistic menu artwork

This revision replaces the category illustrations with real AI-generated raster product images and adds an image for each of the 51 existing menu entries. The approved counter, category navigation, colors, modal layout and menu names are retained. Per-item native disclosures reveal the larger image and a clear illustrative-image / unconfirmed-recipe notice; small lazy thumbnails keep the list readable.

The supplied cup reference provided the black stacked Vital Vibes mark and drink-outline symbol. The transparent raster mark was cleaned using the built-in image tool. It is a reference-based reconstruction, not an original vector master; the unreadable tiny tagline is omitted. The same mark appears reversed for the existing dark header and as a separate print layer on applicable cup mockups. It is deliberately not placed on the third-party bottled beverage or protein add-on, or on the short hot-drink mockups where that print placement is not supported.

All drink imagery is illustrative AI product artwork. Appearance is guided only by the menu names and inspected cup references; it does not establish ingredients, recipes, nutrition, allergens, portion sizes or exact products sold. Generic names with unknown recipes use restrained generic colors and no invented garnish. No prices, contact details, business claims, ordering or payments are added. The concept/menu-confirmation notice and noindex directives remain.

Generation uses the built-in image_gen tool, one distinct call per menu entry. No paid API fallback, service or dependency install is used. A Windows local-reference-path validation failed before generation; drinking-vessel references were inspected and described explicitly in the prompts. The logo cleanup used the visible supplied reference. The original PNGs and raw source screenshots remain outside application/public source. Production derivatives use transparent WebP, 600×900 item images and 144×216 thumbnails, loaded only when their category/item is explored. The complete per-item prompt set and source/output hashes are retained in the task's artwork records.

Verification must establish all 51 unique image mappings and 102 derivatives, actual logo loading, preserved menu data/layout/customer isolation, responsive/keyboard behavior, scoped lint and production build, then required exact-head PR CI before the explicitly authorized merge/publication. Physical-device and screen-reader testing are not claimed.
