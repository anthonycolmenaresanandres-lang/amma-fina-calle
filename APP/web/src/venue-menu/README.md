# Venue menu architecture

The approved, reusable visual baseline is documented in [OPERATIONS/MENU_DRAFT_BASELINE.md](../../../../OPERATIONS/MENU_DRAFT_BASELINE.md), pinned to Olympia PR336 commit `eeafc98bba32040490166994def4dd265245e386`.

Reuse this folder's layout/navigation slots and content conventions. Keep each customer's logos, photos, lettering, palette, menu/prices, claims and game routes in its own namespace. The baseline explains the open layout, accessible native disclosures and optional persistent Play control; it does not authorize copying customer assets or publishing a draft.
