# Bodega Fall Sessions artwork

Created for Anthony's approved seasonal-menu update using the built-in image-generation tool. Final prompts are in prompts.json. Individual WebP illustrations are 400px maximum edge; hero is 1200x800. Original generation PNGs remain in the session workspace.

Source: supplied fall board 37497.png; green cup photo 37475.jpg (also shown in 37499.png); existing Bodega transparent game cup and original round seal in public/assets/bodega/review. Original animated menu logo component was not changed.

The five named drinks and descriptions are transcribed from the board. The Spiced Apple Chai description is cropped, so omitted. Prices, serving formats and current availability are not established by these illustrations. The green drink is intentionally unnamed: do not call it matcha or assign a menu name until Anthony supplies one.

Art files: maple-morning.webp, autumn-brew.webp, haystack.webp, sugar-n-spice.webp, spiced-apple-chai.webp, green-drink.webp, fall-sessions-hero.webp.
